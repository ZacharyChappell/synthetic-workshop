# synthetic-workshop v0.1.0-alpha.1

Initial pre-alpha public software snapshot.

This release provides the first citable version of `synthetic-workshop`, a Python package for generating analytic synthetic 2D and 3D image scenes for image-method validation.

## Included

- Grid and coordinate helpers.
- Compositional scene model.
- YAML/JSON scene loading.
- Analytic tube and implicit-object rendering.
- Circular, elliptic, variable, ribbon, superellipse, and rotating-ellipse cross-sections.
- Radial and structured scalar profiles.
- Object roles, masks, labels, overlap reports, and composition metadata.
- Graph, graph-centreline, and graph-tube topology modules.
- NumPy/TSV/JSON export.
- Projection, slice, skeleton, legend, and gallery plotting.
- Small public example scenes.
- Test coverage for core geometry, rendering, profiles, cross-sections, topology, IO, plotting, GUI helpers, and scene workflows.

## Status

This is an early pre-alpha release. The public API may change, and the package should be treated as a citable development snapshot rather than a stable production interface.
