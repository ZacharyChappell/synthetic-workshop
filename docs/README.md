# Documentation

This folder contains concise public documentation for `synthetic-workshop`.

`synthetic-workshop` builds analytic synthetic image scenes for method validation. A scene combines a grid, one or more analytic objects, scalar profiles, masks, labels, centrelines, frames, composition metadata, and exportable outputs.

## Contents

- `concepts.md` explains the main modelling concepts.
- `scene_schema.md` describes the YAML/JSON scene format.
- `python_api.md` gives a short Python usage guide.
- `examples.md` describes the included example scenes.
- `outputs.md` describes the exported arrays, tables, and metadata.
- `plotting.md` describes gallery and inspection figures.
